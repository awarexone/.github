## What We Do

### AI & Application Security

Security tools for AI-built applications, AI agents, APIs, source code, and modern software — so issues are found before they ship.

### Offensive Security

Vulnerability discovery, penetration testing, bug bounty research, and application security testing — against real systems, with written authorisation and agreed scope.

### Human & Social Engineering Security

Defense and training around phishing, vishing, SMiShing, callback phishing, impersonation, and AI/deepfake social engineering — then rebuilding the judgement those attacks depend on.

### Digital Protection & Recovery

Account and social media recovery support, exposure removal, and executive / VIP digital protection. Families are covered as standard. We do not guarantee recovery outcomes.

Based in Malaysia. Working worldwide.

## Open Source

AwareXone builds practical, permissively licensed, self-hostable security tools. No telemetry, no gated tier, no upgrade path that quietly becomes the product.

### AXguard

Helps developers scan code, find security issues, understand findings, fix vulnerabilities, re-scan, generate reports, and add checks to CI.

→ [github.com/Awarexone/AXguard](https://github.com/Awarexone/AXguard)

### Agentic Bug Hunter

AXguard protects what you build. Agentic Bug Hunter helps find vulnerabilities in what is already live.

→ [github.com/Awarexone/Agentic-Bug-Hunter](https://github.com/Awarexone/Agentic-Bug-Hunter)

### Public Skills Builder

Turns published HackerOne reports and GitHub write-ups into working agent skills across vulnerability classes. Nothing confidential goes in or out.

→ [github.com/Awarexone/public-skills-builder](https://github.com/Awarexone/public-skills-builder)

### Web3 Bug Bounty AI Skills

A smart contract security skill library built from Immunefi reports, DeFiHack reproductions, and real hunt experience — patterns that show up in the wild, not only textbook lists.

→ [github.com/Awarexone/web3-bug-bounty-hunting-ai-skills](https://github.com/Awarexone/web3-bug-bounty-hunting-ai-skills)

Alongside the tools, we publish anonymised pretexts from engagements so defenders learn about a technique before it reaches them.
